# STAR Architecture

Authoritative repository for STAR architecture, product-delivery foundations, and related versioned engineering knowledge.

Material changes are reviewed through pull requests. Working baselines are not considered frozen merely because they are stored in this repository.

## Governance entry points

- [STAR OS Global Governance](docs/star-os/README.md) — cross-conversation working rules, bootstrap protocol, scoped decisions and handoff.

Sensitive employee, AI-account, customer and operational risk records must be kept in an approved private governance system, not this public repository.
