# STAR OS Global Governance Changelog

All material changes to the cross-conversation governance baseline are recorded here.

## [0.1.1] — 2026-07-13

### Added

- `05_CONVERSATION_HANDOFF_TEMPLATE.md` for durable cross-conversation transfer.
- `06_BOOTSTRAP_CHECKLIST.md` for auditable startup inheritance.
- Initial `⭐ STAR AI Governance` handoff record.

### Strengthened

- Made responsibility for retrieving and applying prior confirmed decisions explicit.
- Required new conversations to request only genuine deltas or missing authoritative facts, not repeat confirmation.
- Added repository and workstream entry points so global governance can be found before domain work.

## [0.1.0] — 2026-07-13

### Added

- `00_GLOBAL_WORKING_RULES.md`.
- `01_GLOBAL_DECISION_LOG.md` with `GDEC-0001` through `GDEC-0007`.
- `02_CONVERSATION_BOOTSTRAP_PROTOCOL.md`.
- `03_DECISION_SCOPE_AND_PROPAGATION.md`.
- `04_WORKSTREAM_REGISTRY.md`.

### Established

- Confirm once, record once, inherit everywhere within scope.
- Global → Domain → Product/Program → Mission → Task decision inheritance.
- Explicit reconfirmation conditions and conflict handling.
- Public/private information boundary for workstream registration.
