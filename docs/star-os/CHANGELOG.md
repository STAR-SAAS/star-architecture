# STAR OS Global Governance Changelog

## [0.1.0] — 2026-07-13

### Added

- `README.md` as the global-governance entry point.
- `STAR_OS_GLOBAL_WORKING_RULES.md` with confirmed cross-cutting disciplines and the Self-Review Gate.
- `STAR_CONVERSATION_BOOTSTRAP_PROTOCOL.md` for new, resumed and transferred conversations.
- `STAR_DECISION_SCOPE_AND_PROPAGATION.md` for scope, propagation, conflict and exception handling.
- `STAR_GLOBAL_DECISION_LOG.md` with the first confirmed global decisions.
- `STAR_CONVERSATION_HANDOFF_TEMPLATE.md` for reliable context transfer.
- `STAR_PROJECT_INSTRUCTIONS_SNIPPET.md` to provide a one-time bootstrap pointer in supported AI workspaces.

### Purpose

- Prevent users from repeating confirmed rules in every new conversation.
- Separate global disciplines from domain-specific policies.
- Require self-review after every material task before continuing.
- Make durable Markdown, rather than chat memory, the governed source for cross-conversation rules.

### Limitations

- Markdown cannot automatically load itself into every AI conversation.
- Project Instructions, agent configuration, an opening bootstrap pointer or approved automation is still required.
- Sensitive employee, AI-account, customer and risk records must not be placed in this public repository.
- The baseline remains a working candidate until reviewed and merged.
