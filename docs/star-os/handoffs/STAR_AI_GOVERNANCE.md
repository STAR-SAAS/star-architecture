## Inherited confirmed rules

- Do not ask the user to repeat or reconfirm an applicable confirmed decision merely because the conversation changed (`GDEC-0002`).
- Run the Conversation Bootstrap Protocol before material work (`GDEC-0003`).
- Record material decisions with scope, owner, source, propagation and supersession metadata (`GDEC-0004`).
- A domain rule may specialize but may not silently contradict Global rules (`GDEC-0005`).
- After each material task/document, self-review, correct defects, update durable records and then continue (`GDEC-0006`).
- AI may contribute, but accountability and approval remain with named humans or approved governance bodies (`GDEC-0007`).

## Domain objective

Create and implement a company-wide governance system for:

- company, project, employee-working and AI memory;
- approved AI tools, models, vendors and enterprise accounts;
- data classification, privacy, security and retention;
- AI-assisted development, code review, testing and software supply chain;
- approved technology profiles, reference paths and exception handling;
- employee onboarding, offboarding, audit, incidents and cost governance;
- human/AI authority, accountability and evidence.

## First implementation batch

1. Select the private authoritative repository/system for restricted AI Governance records.
2. Establish the domain Charter, Decision Log, Open Questions, Work Status and Changelog.
3. Create a private current-state inventory template for AI tools, accounts, projects, technology stacks and data classes.
4. Draft interim AI-use red lines and an incident/escalation path.
5. Define the five-layer memory model: Company, Project, Work Session, AI Persistent Memory and Operational Evidence.
6. Define approved technology profiles and a lightweight exception process.
7. Plan migration of durable knowledge from personal AI workspaces into company-owned project sources.

## Decision gates

- accountable AI Governance owner/body;
- approved enterprise AI tools and account model;
- data-classification and prohibited-input rules;
- default technology profiles and exception authority;
- enforcement and rollout sequence.
