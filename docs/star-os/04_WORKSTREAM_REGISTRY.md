## Registration rule

A new long-lived STAR conversation or workstream should not remain only as a chat title. Register:

- scope and purpose;
- accountable owner / maintaining group;
- authoritative source location;
- Decision Log and Work Status location;
- access classification;
- parent workstream and inherited rules;
- current lifecycle status.

## Missing-source rule

A workstream with no registered authoritative source remains visible here as **Source not yet registered**. Do not invent its history or ask the user to repeat every decision. Search available records first, then request only the smallest missing factual input needed to establish the source.
