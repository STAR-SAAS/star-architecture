## Purpose

This directory contains rules that apply across STAR conversations, domains, products, Missions and AI collaborators.

A person should not need to repeat a previously confirmed STAR rule whenever a new conversation is created. New work must inherit the relevant global and domain records before asking for confirmation.

## Core rule

> Confirm once, record once, inherit everywhere within scope.

Reconfirmation is required only when a decision is being changed, superseded, applied outside its original scope, invalidated by new evidence, or replaced by a genuinely new executive choice.
