## Authoring rules

1. Context is a derived task view, not a new authoritative source.
2. Link current sources and include version/date/status/provenance.
3. Include only information needed for this task.
4. Never place secret values in this file.
5. A material scope change requires context refresh or new authorization.
6. AI output remains candidate until required checks and human review are complete.
