## Authoring rules

1. Keep the first view to approximately one page.
2. Write for the full cross-functional team, not only engineering.
3. Use plain language and measurable outcomes.
4. Name exclusions, owners and approvers explicitly.
5. Do not duplicate detailed specifications; link authoritative sources.
6. Do not mark the Mission closed merely because code was merged.
7. Remove a stakeholder category only after checking and marking it not affected.
