## Authoring rules

1. Record consequential choices, not routine implementation details.
2. Use one generic format first; specialize only when a proven gap exists.
3. Keep rejected options and rationale so the same debate is not repeated without new evidence.
4. A newer decision supersedes the old one; do not rewrite accepted history silently.
5. AI may draft a Decision Record, but an accountable human owns and accepts it.
