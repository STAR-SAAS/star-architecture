## Integrity guidance

Git commits and Git object IDs are the authoritative integrity mechanism. A manually maintained checksum table is intentionally not used because incremental commits make it stale unless automation regenerates it.

For an exact reviewed snapshot, use the commit SHA or merged pull-request SHA.
